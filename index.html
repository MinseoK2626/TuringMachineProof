02 / THE LIMITS OF COMPUTATION

Three left moves. An undecidable question.

“On input w, does M ever move its head left three times in a row?”

UNDECIDABILITY
ATM ≤m LEFT₃

An algorithm that always decides this question
would also decide ATM, which is impossible.

THE PRECISE PROBLEM

LEFT₃ = { ⟨M,w⟩ | the move sequence of M(w) contains LLL }

Two-way infinite tape · Moves L, R, S · Three consecutive transitions
01 / CONSTRUCT

An effective construction

On blank input, N writes the hardcoded w using only R moves. For n = |w| > 0, it returns to the origin using R followed by n+1 copies of LRL, then simulates M. For w = ε, a harmless RL pair leaves the head at the origin. The transformation replaces finitely many states and transitions without running M in advance.

02 / EQUIVALENCE

Acceptance ⇔ LLL occurs

If M accepts, N executes RLLL and halts. If M rejects, N rejects. If M runs forever, N continues its safe simulation. Therefore ⟨M,w⟩ ∈ ATM ⇔ ⟨N,ε⟩ ∈ LEFT₃.

03 / CONTRADICTION

A decider yields a contradiction

If a decider H for LEFT₃ existed, we could run H on the constructed ⟨N,ε⟩ to decide ATM. Since ATM is undecidable, no such H exists.
