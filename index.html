신호를 보낸다.

입력 ⟨M,w⟩로부터 새 머신 N을 만듭니다. N은 M(w)를 안전하게 시뮬레이션하고, 수락했을 때만 LLL을 실행합니다.

교육용 예시 실행입니다. 유한한 실행 기록만으로 비종료를 판정할 수는 없습니다.

L → LRLR → RS → RL

각 매크로는 원래 이동과 같은 위치에서 끝나며, 중간 이동은 읽은 기호를 그대로 씁니다. 경계에 LL은 생겨도 LLL은 생기지 않습니다.

PHYSICAL HEAD MOVEMENTS
⟨M, w⟩→⟨N, ε⟩→LEFT₃ 판정기?
01 / CONSTRUCT

계산 가능한 변환

N은 입력을 무시하고 w를 테이프에 씁니다(R 이동만 사용). 길이 n = |w| > 0이면 R을 한 번, LRL을 n+1번 실행해 시작점으로 돌아온 뒤 M을 시뮬레이션합니다. w = ε이면 준비 이동은 없습니다. 변환은 M을 미리 실행하지 않고 상태와 전이를 유한하게 치환합니다.

02 / EQUIVALENCE

수락 ⇔ LLL 발생

M이 수락하면 N은 RLLL을 실행하고 멈춥니다. 거부하면 N도 거부하고, 비종료면 안전한 시뮬레이션을 계속합니다. 따라서 ⟨M,w⟩ ∈ ATM ⇔ ⟨N,ε⟩ ∈ LEFT₃.

03 / CONTRADICTION

판정기를 가정하면 모순

LEFT₃의 결정기 H가 있다면, 변환된 ⟨N,ε⟩에 H를 실행하여 ATM을 결정할 수 있습니다. ATM은 결정 불가능하므로 H는 존재하지 않습니다.
